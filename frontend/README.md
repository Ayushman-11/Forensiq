# 🖥️ Forensiq SOC Workspace (Frontend)

The **Forensiq Frontend** is a modern, responsive, and data-dense web application built specifically for Security Operations Center (SOC) analysts. It serves as the single-pane-of-glass for the Forensiq platform, taking the complex output of the LangGraph AI pipeline and rendering it into actionable, human-readable dashboards.

---

## 🛠️ Technology Stack

We chose a cutting-edge stack to ensure the UI is fast, dynamic, and strictly typed:

- **Framework**: [Next.js 15](https://nextjs.org/) (Utilizing the App Router paradigm)
- **UI Library**: React 19
- **Language**: TypeScript
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Data Visualization**: [@mui/x-charts](https://mui.com/x/react-charts/)
- **Icons**: React Icons / Lucide

---

## ✨ Design & Aesthetic Philosophy

Forensiq follows a **"Sleek Glassmorphic Dark Mode"** aesthetic.
- **Theme**: Deep midnight blue/black (`#0A0D14`) backgrounds with slightly elevated dark navy (`#131722`) surface cards.
- **Accents**: Cyan/Teal brand coloring combined with stark severity indicators (Crimson for Critical, Amber for High, Toxic Green for Medium).
- **Layout**: A dense, highly structured 3-column grid dashboard layout to maximize the amount of telemetry data visible to an analyst without requiring scrolling.

---

## 🧩 Core Features & Views

### 1. SOC Overview Dashboard (`/src/app/page.tsx`)
The landing page provides a macro-view of the organization's security posture.
- **KPI Metrics**: Cards displaying Total Alerts, Critical Severity counts, average AI Confidence, and Mean Time to Detect (MTTD).
- **Interactive Visualizations**: Dynamic Line, Pie, and Bar charts rendering alert trends over time, severity distributions, and investigator workloads.
- **Recent Alerts Grid**: A real-time table of incoming threats showing MITRE tactics, Host/User info, and AI confidence badges.

### 2. Alert Investigation View (`/src/app/alerts/page.tsx`)
A dedicated, deep-dive workspace for investigating a specific alert.
- **Context Panel** (`ContextPanel.tsx`): Displays the raw extracted context (IPs, Domains, Hashes, Users) gathered by the backend `context_agent`.
- **Enrichment Panel** (`EnrichmentPanel.tsx`): Displays external threat intelligence (e.g., VirusTotal scores, reputation tags) generated by the `ioc_agent`.

### 3. Historical Search (`/src/app/search/page.tsx`)
A powerful interface allowing analysts to search through normalized historical alerts and SIEM telemetry.

## 🚀 Running the Frontend Locally

If you wish to develop on the frontend independently of the backend startup scripts:

### 1. Install Dependencies
Navigate to the `frontend` directory and install the Node modules:
```bash
cd frontend
npm install
```

### 2. Start the Development Server
Run the Next.js development server:
```bash
npm run dev
```

### 3. View the Application
Open [http://localhost:3000](http://localhost:3000) in your browser.

> **⚠️ Important Note**: The frontend relies on the FastAPI backend for live data. Ensure the backend is running on `http://localhost:8000` to populate the dashboards. If the backend is unreachable, the frontend will attempt to gracefully fall back to mock data or display loading states.
